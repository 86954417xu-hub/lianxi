# 功能说明

## 1. 功能概览

"敲木鱼"应用提供两大核心功能模块：

| 功能模块 | 主要功能 | 交互方式 |
|---------|---------|---------|
| 木鱼敲击 | 点击木鱼增加功德计数 | 点击/触摸 |
| 念珠拨动 | 滑动拨动108颗念珠 | 手势滑动 |

---

## 2. 木鱼敲击功能

### 2.1 功能描述

用户通过点击屏幕上的木鱼图片，模拟敲击木鱼的体验。每次敲击会增加功德计数，并伴随动画和震动反馈。

### 2.2 操作流程

```
用户点击木鱼 
  → 木鱼缩放动画
  → 震动反馈
  → 漂浮文字上升
  → 功德计数+1
  → 自动保存数据
```

### 2.3 详细功能说明

#### 2.3.1 木鱼显示

**位置**: 屏幕中央  
**样式**: 
- 默认提供两种样式：woodfish1.png、woodfish2.png
- 支持用户自定义上传图片

**代码位置**: `src/components/WoodFish.tsx`

```typescript
// 木鱼组件支持预设图片和自定义图片
source={customImage ? {uri: customImage} : woodfishImages[type]}
```

#### 2.3.2 敲击交互

**触发条件**: 
- 单指点击木鱼区域
- 支持快速连续敲击

**动画效果**:
- 缩放动画：木鱼放大后恢复原状
- 动画时长：约100-200ms
- 代码实现：使用 React Native Animated API

```typescript
// 敲击动画实现
Animated.sequence([
  Animated.timing(scaleAnim, {
    toValue: 1.1,
    duration: 100,
    useNativeDriver: true,
  }),
  Animated.timing(scaleAnim, {
    toValue: 1.0,
    duration: 100,
    useNativeDriver: true,
  }),
]).start();
```

#### 2.3.3 漂浮文字

**显示内容**: 
- 默认文案："功德+1"
- 支持自定义文案（如"心诚则灵"、"阿弥陀佛"等）

**动画效果**:
- 从木鱼位置向上飘动
- 逐渐透明直至消失
- 持续时间：约1500ms

**代码位置**: `src/screens/WoodenFishApp.tsx` (第506-540行)

```typescript
// 漂浮文字动画
const addFloatingText = () => {
  const id = Date.now();
  const newFloatingText = {
    id,
    text: floatingText || '功德+1',
    yPosition: new Animated.Value(0),
    opacity: new Animated.Value(1),
  };
  
  // 向上飘动动画
  Animated.parallel([
    Animated.timing(newFloatingText.yPosition, {
      toValue: -150,
      duration: 1500,
      useNativeDriver: true,
    }),
    Animated.timing(newFloatingText.opacity, {
      toValue: 0,
      duration: 1500,
      useNativeDriver: true,
    }),
  ]).start();
};
```

#### 2.3.4 震动反馈

**触发条件**: 每次敲击时  
**震动时长**: 约50ms  
**实现方式**: React Native Vibration API

**代码位置**: `src/screens/WoodenFishApp.tsx`

```typescript
import { Vibration } from 'react-native';

// 震动反馈
if (soundEnabled) {
  Vibration.vibrate(50);
}
```

#### 2.3.5 功德计数

**计数方式**: 
- 每次点击木鱼，计数+1
- 累积计数，不清零

**数据存储**: 
- 使用 AsyncStorage 本地存储
- 键名：`woodenFishCount`
- 自动保存，应用重启后恢复

**代码位置**: `src/screens/WoodenFishApp.tsx`

```typescript
import AsyncStorage from '@react-native-async-storage/async-storage';

// 保存计数
const saveWoodFishCount = async (count: number) => {
  try {
    await AsyncStorage.setItem('woodenFishCount', count.toString());
  } catch (error) {
    console.error('保存计数失败:', error);
  }
};

// 加载计数
const loadWoodFishCount = async () => {
  try {
    const count = await AsyncStorage.getItem('woodenFishCount');
    return count ? parseInt(count, 10) : 0;
  } catch (error) {
    console.error('加载计数失败:', error);
    return 0;
  }
};
```

## 3. 念珠拨动功能

### 3.1 功能描述

用户通过手势滑动拨动108颗念珠，模拟真实念珠的使用体验。每次拨动一颗珠子，功德计数增加，并伴随震动反馈。

### 3.2 操作流程

```
用户滑动手指
  → 念珠跟随手指移动
  → 累积滑动距离
  → 到达一颗珠子距离（60px）
  → 功德计数+1
  → 震动反馈
  → 漂浮文字上升
  → 自动保存数据
```

### 3.3 详细功能说明

#### 3.3.1 念珠显示

**珠子数量**: 108颗（传统佛教念珠数量）  
**珠子样式**: 
- 图片：rosary_bead.png
- 大小：60x60px
- 间距：90px

**显示方式**: 
- 虚拟滚动：只渲染可见区域的珠子
- 性能优化：避免一次性渲染108颗珠子

**代码位置**: `src/screens/WoodenFishApp.tsx` (第645-750行)

```typescript
// 虚拟滚动优化
const totalBeadHeight = 150; // 每颗珠子占用高度（60px珠子 + 90px间距）
const visibleBeads = [];
const currentBeadIndex = Math.floor(totalScrollPos / totalBeadHeight);

// 只渲染当前可见的珠子（前后各几颗）
for (let i = -3; i <= 3; i++) {
  const beadIndex = (currentBeadIndex + i + 108) % 108; // 108颗循环
  visibleBeads.push({
    index: beadIndex,
    offset: i,
    basePosition: beadIndex * totalBeadHeight,
  });
}
```

#### 3.3.2 滑动交互

**手势识别**: 
- 使用 PanResponder 捕获手势
- 支持垂直方向的滑动

**滚动实现**:
- 使用 Animated.View 实现平滑滚动
- 滚动偏移量：`scrollOffsetAnim`

**代码位置**: `src/screens/WoodenFishApp.tsx` (第267-320行)

```typescript
const rosaryPanResponder = useRef(
  PanResponder.create({
    onStartShouldSetPanResponder: () => true,
    onMoveShouldSetPanResponder: () => true,
    onPanResponderGrant: () => {
      lastGestureDy.current = 0;
      initialScrollY.current = totalScrollPosition.current;
      hasScrolled.current = false;
    },
    onPanResponderMove: (_, gestureState) => {
      const deltaDy = gestureState.dy - lastGestureDy.current;
      lastGestureDy.current = gestureState.dy;
      
      totalScrollPosition.current += deltaDy;
      hasScrolled.current = true;
      
      scrollOffsetAnim.setValue(
        (totalScrollPosition.current - initialScrollY.current) % 60
      );
    },
    onPanResponderRelease: () => {
      if (hasScrolled.current) {
        // 增加功德计数
        setRosaryCount(prevCount => prevCount + 1);
        addRosaryFloatingText();
        if (soundEnabled) {
          Vibration.vibrate(200);
        }
      }
      scrollOffsetAnim.setValue(0);
    },
  })
).current;
```

#### 3.3.3 功德计数

**计数方式**: 
- 每次滑动结束（松手），计数+1
- 累积计数，与木鱼敲击独立计数

**数据存储**: 
- 使用 AsyncStorage 本地存储
- 键名：`rosaryCount`
- 额外存储：`currentBead`（当前珠子位置）

#### 3.3.4 漂浮文字

**显示内容**: 自定义祈福文案  
**动画效果**: 向上飘动并消失  
**触发时机**: 每次滑动结束

#### 3.3.5 震动反馈

**触发条件**: 每次滑动结束时  
**震动时长**: 约200ms  
**特点**: 比木鱼敲击的震动更长，增加仪式感

### 4.3 详细设置说明

#### 4.3.1 木鱼图片设置

**预设样式**: 
- woodfish1.png（50.26 KB）
- woodfish2.png（147.24 KB）

**自定义图片**: 
- 从相册选择图片
- 自动裁剪和压缩
- 保存到应用缓存目录

**代码位置**: `src/utils/ImageStorage.ts`

```typescript
// 保存自定义图片
export const saveImage = async (): Promise<string | null> => {
  const options: ImageLibraryOptions = {
    mediaType: 'photo',
    quality: 0.8,
    includeBase64: false,
  };
  
  const result = await launchImageLibrary(options);
  
  if (result.didCancel || result.errorCode) {
    return null;
  }
  
  const source = result.assets[0].uri;
  const fileName = 'custom_woodfish.png';
  const destPath = `${CachesDirectoryPath}/woodenfish/${fileName}`;
  
  await RNFS.mkdir(`${CachesDirectoryPath}/woodenfish`);
  await RNFS.copyFile(source, destPath);
  
  return destPath;
};
```

## 5. 数据存储与持久化

### 5.1 存储方案

应用使用混合存储策略：

| 数据类型 | 存储方式 | 存储位置 |
|---------|---------|---------|
| 用户设置 | AsyncStorage | 应用沙箱 |
| 计数数据 | AsyncStorage | 应用沙箱 |
| 自定义图片 | 文件系统 | 缓存目录 |
| 自定义音效 | 文件系统 | 缓存目录 |

### 5.2 数据键名映射

| 键名 | 数据类型 | 说明 |
|-----|---------|------|
| woodenFishCount | number | 木鱼敲击计数 |
| rosaryCount | number | 念珠拨动计数 |
| currentBead | number | 当前珠子位置 |
| woodFishType | number | 木鱼样式（1或2） |
| customWoodFishImage | string | 自定义图片路径 |
| customSoundPath | string | 自定义音效路径 |
| floatingText | string | 漂浮文案 |
| textColor | string | 文字颜色 |
| soundEnabled | boolean | 音效/震动开关 |

### 5.3 数据恢复

应用启动时自动加载所有存储的数据：

```typescript
// 应用启动时加载数据
useEffect(() => {
  loadData();
}, []);

const loadData = async () => {
  const count = await loadWoodFishCount();
  const rosaryCount = await loadRosaryCount();
  const customImage = await getSavedImagePath();
  const customSound = await getSavedAudioPath();
  const text = await AsyncStorage.getItem('floatingText');
  const color = await AsyncStorage.getItem('textColor');
  // ... 更新状态
};
```

**行为**: 双击返回键退出应用  
**实现**: 使用 BackHandler API

```typescript
import { BackHandler } from 'react-native';

useEffect(() => {
  const backHandler = BackHandler.addEventListener(
    'hardwareBackPress',
    () => {
      if (lastBackPress.current && Date.now() - lastBackPress.current < 2000) {
        return false; // 退出应用
      }
      lastBackPress.current = Date.now();
      ToastAndroid.show('再按一次退出应用', ToastAndroid.SHORT);
      return true; // 阻止默认行为
    }
  );
  
  return () => backHandler.remove();
}, []);
```

## 7. 性能优化

### 7.1 渲染优化

- **虚拟滚动**: 念珠页面只渲染可见区域的珠子
- **动画优化**: 使用 `useNativeDriver: true` 提升动画性能
- **状态优化**: 使用 `useMemo` 和 `useCallback` 减少不必要的渲染

### 7.2 存储优化

- **异步保存**: 数据保存不阻塞主线程
- **批量保存**: 多个设置项同时保存
- **缓存机制**: 图片和音效缓存到本地

### 7.3 内存优化

- **图片压缩**: 自定义图片自动压缩到合适大小
- **资源释放**: 组件卸载时清理定时器和监听器
