# 产品概述

## 1. 产品定位

"敲木鱼"是一款专注于禅修、冥想和精神放松的移动应用。通过数字化的方式模拟传统木鱼敲击和念珠拨动的体验，为用户提供便捷的祈福、冥想辅助工具。

### 产品特色

- **传统与现代结合**: 将传统的佛教修行工具数字化，保留文化内涵
- **极简设计**: 简洁清新的界面设计，专注核心功能
- **高度可定制**: 支持个性化设置，满足不同用户需求
- **跨平台体验**: 基于 React Native 开发，提供流畅的原生体验

---

## 2. 核心价值

### 2.1 精神慰藉

在快节奏的现代生活中，为用户提供一个简单的心灵寄托方式。通过敲击木鱼、拨动念珠等互动，帮助用户：
- 缓解压力和焦虑
- 获得内心的平静
- 培养专注力和正念

### 2.2 便捷性

- **随时随地**: 无需携带实体木鱼或念珠，手机即可完成
- **数据持久化**: 自动保存功德计数和设置，永不丢失
- **即时反馈**: 震动、音效等多感官反馈，增强体验

### 2.3 个性化体验

- **自定义木鱼图片**: 支持上传个人喜好的木鱼样式
- **自定义音效**: 可上传专属的敲击音效
- **自定义文案**: 个性化漂浮文字（如"功德+1"、"心诚则灵"等）
- **样式选择**: 提供多种预设木鱼样式

---

## 3. 目标用户分析

### 3.1 核心用户群体

#### 主要用户
- **年龄层**: 25-45岁
- **职业**: 白领、学生、自由职业者
- **特征**: 对传统文化感兴趣，追求精神慰藉，生活压力大

#### 次要用户
- **年龄层**: 18-25岁、45岁以上
- **特征**: 对佛教文化好奇，或已有修行习惯

### 3.2 用户需求分析

| 用户类型 | 主要需求 | 产品解决方案 |
|---------|---------|-------------|
| 禅修爱好者 | 简洁专注的工具 | 极简设计，核心功能突出 |
| 压力大的上班族 | 快速解压方式 | 随时可用的祈福计数 |
| 文化探索者 | 体验传统文化 | 数字化传统工具 |
| 个性化追求者 | 独特体验 | 高度可定制功能 |

### 3.3 使用场景

1. **日常祈福**: 早晨起床、睡前等固定时间进行祈福
2. **压力释放**: 工作间隙、感到焦虑时快速解压
3. **冥想辅助**: 配合冥想练习，增强仪式感
4. **文化体验**: 了解体验传统佛教文化

---

## 4. 产品特性

### 4.1 核心功能

#### 木鱼敲击
- 点击木鱼增加功德计数
- 实时震动反馈
- 漂浮文字动画效果
- 累计功德统计

#### 念珠拨动
- 108颗念珠循环
- 手势滑动拨动
- 累积功德计数
- 平滑滚动动画

#### 自定义设置
- 木鱼图片选择（预设/自定义）
- 敲击音效设置
- 漂浮文案自定义
- 文字颜色调整

### 4.2 技术特性

- **离线可用**: 所有数据本地存储，无需网络
- **数据持久化**: AsyncStorage 自动保存，应用重启恢复
- **流畅动画**: 60fps 流畅动画体验
- **低功耗**: 优化的动画和渲染，降低电量消耗

### 4.3 设计特性

- **极简美学**: 灰白色调，简洁清新
- **直观交互**: 自然的手势操作
- **视觉反馈**: 丰富的动画和视觉提示
- **无障碍**: 支持系统辅助功能

---

## 5. 产品优势

### 5.1 相比传统工具

| 维度 | 传统木鱼/念珠 | 敲木鱼 APP |
|-----|-------------|-----------|
| 便携性 | 需随身携带 | 随时可用 |
| 计数准确性 | 手动计数，易出错 | 自动计数，准确无误 |
| 个性化 | 固定样式 | 高度可定制 |
| 数据保存 | 容易遗忘 | 永久保存 |
| 成本 | 需购买实体 | 免费使用 |

### 5.2 相比同类应用

- **更专注**: 只做核心功能，不做冗余
- **更流畅**: React Native 原生性能
- **更开放**: 高度自定义，不强制付费
- **更纯粹**: 无广告干扰，清静修行
