### 2.2 数据流架构

应用采用 **单向数据流** 设计：

```
用户操作 (User Action)
    ↓
事件处理 (Event Handler)
    ↓
状态更新 (State Update)
    ↓
UI 渲染 (Render)
    ↓
数据持久化 (Data Persistence)
```

**示例：木鱼敲击数据流**

```
用户点击木鱼
    ↓
onPress 事件触发
    ↓
handleWoodFishPress()
    ↓
setCount(prev => prev + 1)
    ↓
UI 更新（显示新计数）
    ↓
saveWoodFishCount(newCount)
    ↓
AsyncStorage 存储
```

### 2.3 状态管理

应用使用 React Hooks 进行状态管理，分为三类状态：

#### 2.3.1 全局状态（Global State）
存储在 `WoodenFishApp.tsx` 中，通过 props 传递给子组件：

| 状态 | 类型 | 说明 |
|------|------|------|
| count | number | 木鱼敲击计数 |
| rosaryCount | number | 念珠拨动计数 |
| currentBead | number | 当前珠子位置 |
| woodFishType | number | 木鱼样式 |
| customImage | string | 自定义图片路径 |
| customSound | string | 自定义音效路径 |
| floatingText | string | 漂浮文案 |
| textColor | string | 文字颜色 |
| soundEnabled | boolean | 音效开关 |

#### 2.3.2 本地状态（Local State）
组件内部状态，不共享：

```typescript
// 示例：木鱼组件的动画状态
const [scaleAnim] = useState(new Animated.Value(1));
```

#### 2.3.3 持久化状态（Persisted State）
通过 AsyncStorage 持久化，应用重启后恢复：

```typescript
// 加载持久化状态
useEffect(() => {
  loadData();
}, []);

const loadData = async () => {
  const savedCount = await AsyncStorage.getItem('woodenFishCount');
  if (savedCount) {
    setCount(parseInt(savedCount, 10));
  }
};
```

## 5. 性能优化策略

### 5.1 渲染优化

#### 5.1.1 虚拟滚动

念珠页面采用虚拟滚动技术，避免一次性渲染108颗珠子：

```typescript
// 只渲染可见区域的珠子
const visibleBeads = [];
const startIndex = Math.floor(scrollOffset / beadHeight) - 3;
const endIndex = startIndex + 7; // 前后各3颗 + 当前1颗

for (let i = startIndex; i <= endIndex; i++) {
  const actualIndex = ((i % 108) + 108) % 108; // 循环索引
  visibleBeads.push(renderBead(actualIndex));
}
```

#### 5.1.2 原生动画驱动

所有动画使用 `useNativeDriver: true`，在原生线程执行：

```typescript
Animated.timing(animValue, {
  toValue: 1,
  duration: 300,
  useNativeDriver: true,  // 关键优化
}).start();
```

#### 5.1.3 避免不必要渲染

使用 `useMemo` 和 `useCallback` 优化：

```typescript
// 缓存计算结果
const visibleBeads = useMemo(() => {
  return calculateVisibleBeads(scrollOffset);
}, [scrollOffset]);

// 缓存回调函数
const handlePress = useCallback(() => {
  setCount(prev => prev + 1);
}, []);
```

## 6. 安全性设计

### 6.1 数据安全

- **本地存储**: 所有数据存储在应用沙箱内，其他应用无法访问
- **敏感权限**: 仅申请必要权限（存储、震动）
- **无网络请求**: 所有数据本地处理，无网络传输

### 6.2 权限管理

应用申请的权限：

| 权限 | 用途 | 必要性 |
|------|------|--------|
| INTERNET | 网络访问（预留） | 低 |
| READ_EXTERNAL_STORAGE | 读取图片/音频（API ≤ 32） | 高 |
| READ_MEDIA_IMAGES | 读取图片（API ≥ 33） | 高 |
| READ_MEDIA_AUDIO | 读取音频（API ≥ 33） | 高 |
| CAMERA | 相机（预留） | 低 |
| VIBRATE | 震动反馈 | 高 |
