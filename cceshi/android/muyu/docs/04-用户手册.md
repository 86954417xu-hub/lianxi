## 1. 安装部署

### 1.1 系统要求

**Android 设备要求**:

| 项目 | 要求 |
|------|------|
| 操作系统 | Android 6.0 (API 23) 或更高版本 |
| 存储空间 | 至少 50 MB 可用空间 |
| 内存 | 至少 2 GB RAM（推荐） |
| 权限 | 存储、震动权限 |

**支持设备**:
- 华为、小米、OPPO、vivo、三星等主流 Android 手机
- Android 平板（可能存在布局适配问题）

### 1.2 安装方式

#### 方式一：APK 直接安装

1. **下载 APK 文件**
   - 从发布渠道下载 `app-release.apk` 文件
   - 文件大小约 30-50 MB

2. **安装应用**
   - 在文件管理器中找到下载的 APK 文件
   - 点击安装
   - 如果提示"禁止安装未知应用"，请在设置中允许安装

3. **权限授权**
   - 首次启动时，应用会请求必要的权限
   - 建议授予权限以获得完整功能

#### 方式二：应用市场安装

1. 打开应用市场（华为应用市场、小米应用商店等）
2. 搜索"敲木鱼"
3. 点击安装
4. 等待安装完成

### 1.3 开发环境搭建（开发者）

**前置要求**:
- Node.js >= 16
- JDK 17
- Android Studio
- Android SDK (API 35)

**安装步骤**:

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd muyu
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动 Metro 服务器**
   ```bash
   npm start
   ```
   服务器将在端口 8099 启动

4. **运行应用**
   ```bash
   npm run android
   ```

5. **构建 Release 版本**
   ```bash
   cd android
   ./gradlew assembleRelease
   ```
   APK 文件生成位置：`android/app/build/outputs/apk/release/app-release.apk`

## 2. 快速开始

### 2.1 首次启动

安装完成后，点击应用图标启动应用：

```
应用启动
  ↓
加载用户数据（约1-2秒）
  ↓
显示木鱼页面
  ↓
可以开始使用
```

### 2.2 界面导航

应用底部有三个导航标签：

| 标签 | 图标 | 功能 |
|------|------|------|
| 木鱼 | 🪘 | 敲击木鱼，积累功德 |
| 念珠 | 📿 | 拨动念珠，修行计数 |
| 我的 | 👤 | 个人设置（预留） |

**切换方式**: 点击底部标签即可切换

### 2.3 基本操作

#### 木鱼敲击
1. 进入"木鱼"页面
2. 点击屏幕中央的木鱼
3. 每次点击，功德计数+1
4. 同时会有震动反馈和漂浮文字

#### 念珠拨动
1. 进入"念珠"页面
2. 在珠子区域上下滑动
3. 滑动后松手，功德计数+1
4. 108颗珠子循环，可无限拨动

## 3. 功能使用教程

### 3.1 木鱼敲击功能

#### 3.1.1 基本敲击

**操作步骤**:

1. 打开应用，默认进入木鱼页面
2. 点击屏幕中央的木鱼图片
3. 观察效果：
   - 木鱼会有缩放动画
   - "功德+1"文字向上飘动
   - 手机震动反馈
   - 顶部计数器数字增加

**技巧**:
- 可以快速连续点击
- 支持多指同时敲击
- 震动效果可在设置中关闭

#### 3.1.2 查看累计功德

**位置**: 屏幕顶部

**显示内容**:
```
累计功德：123
```

**说明**:
- 计数会自动保存
- 关闭应用后重新打开，计数不会丢失
- 可以累积到任意数字

#### 3.1.3 更换木鱼样式

请参考 [4.1 木鱼样式设置](#41-木鱼样式设置)

---

### 3.2 念珠拨动功能

#### 3.2.1 基本拨动

**操作步骤**:

1. 点击底部"念珠"标签
2. 在珠子显示区域，用手指向上或向下滑动
3. 珠子会跟随手指移动
4. 松手后，功德计数+1
5. 会有震动反馈和漂浮文字

**注意事项**:
- 每次滑动结束后松手才算一次
- 可以快速短距离滑动
- 可以长距离滑动，效果相同

#### 3.2.2 理解念珠循环

**珠子数量**: 108颗（传统佛教念珠标准）

**循环方式**: 
- 无限循环，没有尽头
- 拨动完108颗后，自动回到第1颗
- 可以一直拨动下去

**当前珠子提示**:
- 屏幕中央会显示当前拨动的珠子
- 没有明确的珠子编号显示
- 通过视觉反馈感知当前位置

#### 3.2.3 查看念珠功德

**位置**: 念珠页面顶部

**显示内容**:
```
累积功德：45
```

**说明**:
- 木鱼功德和念珠功德独立计数
- 两者互不影响
- 都会自动保存

### 3.3 自定义功能

#### 3.3.1 自定义木鱼图片

**步骤**:

1. 点击屏幕右上角"设置"图标（齿轮）
2. 选择"更换木鱼图片"
3. 选择图片来源：
   - 预设样式：woodfish1 或 woodfish2
   - 自定义图片：从相册选择
4. 如果选择自定义：
   - 授予相册访问权限
   - 选择一张图片
   - 系统会自动裁剪和保存
5. 返回主页面，木鱼已更换

**支持的图片格式**: JPG、PNG、WEBP

**建议图片大小**: 500x500 像素以下

#### 3.3.2 自定义敲击音效

**步骤**:

1. 进入设置页面
2. 选择"自定义音效"
3. 选择"上传音效"
4. 从文件管理器选择音频文件
5. 系统会自动保存并应用

**支持的音频格式**: MP3、WAV、AAC

**注意**: 
- 当前版本音效功能正在优化中
- 目前主要使用震动反馈

#### 3.3.3 自定义漂浮文案

**步骤**:

1. 进入设置页面
2. 选择"漂浮文案"
3. 输入自定义文字（如"心诚则灵"）
4. 点击保存
5. 返回主页面，敲击木鱼时会显示新文案

**示例文案**:
- 功德+1（默认）
- 心诚则灵
- 阿弥陀佛
- 善哉善哉
- 吉祥如意

**文案长度限制**: 建议2-10个字

#### 3.3.4 自定义文字颜色

**步骤**:

1. 进入设置页面
2. 选择"文字颜色"
3. 从颜色列表中选择喜欢的颜色
4. 点击保存

**可选颜色**:
- 黑色（默认）
- 红色
- 金色
- 蓝色
- 紫色

## 4. 设置指南

### 4.1 木鱼样式设置

#### 预设样式

| 样式 | 特点 |
|------|------|
| 样式1 | 传统木鱼造型，简洁大方 |

## 5. 常见问题

### 5.1 安装问题

#### Q: 无法安装 APK，提示"解析包错误"

**原因**: 
- APK 文件损坏
- Android 版本过低
- 存储空间不足

**解决方法**:
1. 重新下载 APK 文件
2. 检查 Android 版本是否 >= 6.0
3. 清理手机存储空间

#### Q: 提示"禁止安装未知应用"

**原因**: Android 安全设置限制

**解决方法**:
1. 打开手机"设置"
2. 找到"安全"或"应用管理"
3. 找到"安装未知应用"选项
4. 允许文件管理器或浏览器安装应用

#### Q: 安装后无法启动，提示闪退

**原因**: 
- 设备不兼容
- 缓存问题

**解决方法**:
1. 重启手机
2. 清除应用缓存（设置 > 应用 > 敲木鱼 > 清除缓存）
3. 卸载后重新安装

### 5.2 使用问题

#### Q: 点击木鱼没有反应

**可能原因**:
- 触摸屏问题
- 应用卡顿

**解决方法**:
1. 检查屏幕是否正常
2. 重启应用
3. 检查是否有其他应用覆盖屏幕

#### Q: 震动无效

**可能原因**:
- 手机震动功能关闭
- 应用权限未授予
- 手机静音模式

**解决方法**:
1. 检查手机震动设置
2. 检查应用权限（设置 > 应用 > 敲木鱼 > 权限）
3. 确认应用内的震动开关已开启

#### Q: 念珠拨动不灵敏

**可能原因**:
- 手势识别问题
- 触摸屏灵敏度

**解决方法**:
1. 尝试更大幅度的滑动
2. 确保手指在珠子区域内滑动
3. 检查屏幕是否有污渍或保护膜影响触控

#### Q: 自定义图片无法选择

**可能原因**:
- 未授予相册权限
- 系统权限设置问题

**解决方法**:
1. 检查应用权限（设置 > 应用 > 敲木鱼 > 权限）
2. 授予"存储"或"相册"权限
3. 如果是 Android 13+，需要授予"读取图片"权限

### 5.3 数据问题

#### Q: 计数突然归零

**可能原因**:
- 清除了应用数据
- 卸载重装了应用
- 存储空间不足导致数据丢失

**解决方法**:
1. 检查是否误操作清除数据
2. 定期记录重要计数（未来版本会支持数据备份）

#### Q: 设置无法保存

**可能原因**:
- 存储权限问题
- 存储空间不足

**解决方法**:
1. 检查存储权限
2. 清理手机存储空间
3. 重启应用

#### Q: 应用重启后设置丢失

**可能原因**: 
- 数据加载失败
- 存储异常

**解决方法**:
1. 重启应用
2. 重新设置
3. 如果问题持续，卸载重装

### 5.4 性能问题

#### Q: 应用卡顿、动画不流畅

**可能原因**:
- 设备性能不足
- 后台运行应用过多
- 系统资源不足

**解决方法**:
1. 关闭后台不必要的应用
2. 清理手机内存
3. 重启手机
4. 检查是否有系统更新

#### Q: 耗电快

**可能原因**:
- 长时间使用
- 动画效果较多

**解决方法**:
1. 合理使用，避免长时间连续操作
2. 关闭震动反馈可略微省电

#### Q: 应用占用存储空间过大

**可能原因**:
- 自定义图片和音效占用空间
- 缓存文件

**解决方法**:
1. 清除应用缓存（设置 > 应用 > 敲木鱼 > 清除缓存）
2. 重新选择较小的图片

### 5.5 其他问题

#### Q: 如何退出应用？

**方法**: 
1. 按 Android 返回键
2. 提示"再按一次退出应用"
3. 再次按返回键，应用退出

**注意**: 退出后数据会自动保存，下次打开继续使用

#### Q: 应用支持 iOS 吗？

**当前状态**: 不支持

**未来规划**: 计划在 v1.1.0 版本支持 iOS 平台

#### Q: 可以分享我的功德计数吗？

**当前状态**: 不支持

**未来规划**: 计划在 v2.0.0 版本添加社交分享功能
