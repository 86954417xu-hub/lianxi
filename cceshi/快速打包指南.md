# 敲木鱼项目打包指南

## 快速打包步骤

### 方法一：使用批处理脚本（推荐）

直接双击运行以下脚本：
```
d:\cceshi\cceshi\build_release.bat
```

该脚本会自动完成：
- 清理旧的构建文件
- 构建新的 Release APK
- 可选安装到连接的 Android 设备

### 方法二：手动打包

#### 1. 打开命令提示符（CMD）

#### 2. 进入项目 Android 目录
```bash
cd /d "d:\cceshi\cceshi\android\muyu\android"
```

#### 3. 清理旧构建（可选）
```bash
gradlew.bat clean
```

#### 4. 构建 Release APK
```bash
gradlew.bat assembleRelease
```

#### 5. 查找生成的 APK
构建成功后，APK 文件位于：
```
d:\cceshi\cceshi\android\muyu\android\app\build\outputs\apk\release\app-release.apk
```

## 环境要求

### 必需环境
- **Java JDK 17** - 路径：`C:\Program Files\Java\jdk-17`
- **Android SDK** - 路径：`%LOCALAPPDATA%\Android\Sdk`
- **Node.js** - 版本 >= 16

### 环境变量配置
```bash
JAVA_HOME=C:\Program Files\Java\jdk-17
ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk
PATH=%JAVA_HOME%\bin;C:\Program Files\nodejs;%ANDROID_HOME%\platform-tools;%ANDROID_HOME%\cmdline-tools\latest\bin
```

## 构建选项

### 构建 Debug APK
```bash
gradlew.bat assembleDebug
```
APK 位置：`app/build/outputs/apk/debug/app-debug.apk`

### 构建 Release APK
```bash
gradlew.bat assembleRelease
```
APK 位置：`app/build/outputs/apk/release/app-release.apk`

```bash
gradlew.bat assemble
```

## 安装到设备

### 通过 ADB 安装
```bash
# 检查连接的设备
adb devices

# 安装 APK
adb install -r "d:\cceshi\cceshi\android\muyu\android\app\build\outputs\apk\release\app-release.apk"
```

### 手动安装
1. 将 APK 文件传输到手机
2. 在手机上点击 APK 文件
3. 按照提示完成安装

## 常见问题

### 1. gradlew.bat 找不到
**解决方案**：确保在正确的目录下执行命令
```bash
cd /d "d:\cceshi\cceshi\android\muyu\android"
```

### 2. Java 版本不匹配
**解决方案**：
- 安装 JDK 17
- 设置 JAVA_HOME 环境变量
- 确保 PATH 中包含 Java bin 目录

### 3. Android SDK 未找到
**解决方案**：
- 安装 Android Studio 或 Android SDK
- 设置 ANDROID_HOME 环境变量
- 安装必要的 SDK 组件（build-tools, platform-tools）

### 4. 构建失败：Execution failed for task ':app:processDebugResources'
**解决方案**：
```bash
gradlew.bat clean
gradlew.bat assembleRelease
```

### 5. 内存不足错误
**解决方案**：增加 Gradle 内存
在 `gradle.properties` 中添加：
```
org.gradle.jvmargs=-Xmx4096m -XX:MaxMetaspaceSize=1024m
```
