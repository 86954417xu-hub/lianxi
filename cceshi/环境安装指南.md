## 需要手动安装的组件

### 1. Node.js 安装
由于自动安装受限，请手动安装 Node.js：

**下载地址：**
- LTS 版本 (推荐): https://nodejs.org/
- 选择 Windows Installer (.msi) 版本

**安装步骤：**
1. 下载并运行 Node.js 安装程序
2. 勾选 "Automatically install the necessary tools" 选项
3. 完成安装后，重启终端或打开新的 PowerShell
4. 验证安装：
   ```powershell
   node --version
   npm --version
   ```

### 2. Android SDK 安装

**方案A：安装 Android Studio（推荐）**
1. 下载 Android Studio: https://developer.android.com/studio
2. 安装 Android Studio
3. 首次启动时，选择 "Standard" 安装类型
4. 安装完成后，配置环境变量：
   - ANDROID_HOME: `C:\Users\你的用户名\AppData\Local\Android\Sdk`
   - 添加到 PATH: `%ANDROID_HOME%\platform-tools` 和 `%ANDROID_HOME%\cmdline-tools\latest\bin`

**方案B：仅安装 Android SDK Command-line Tools**
1. 下载: https://developer.android.com/studio#command-tools
2. 解压到: `C:\Android\Sdk\cmdline-tools\latest\`
3. 配置环境变量（见下方）

### 3. 环境变量配置

打开 PowerShell，运行：
```powershell
# 临时设置（仅当前会话有效）
$env:JAVA_HOME="C:\Program Files\Java\jdk-17"
$env:ANDROID_HOME="C:\Users\$env:USERNAME\AppData\Local\Android\Sdk"
$env:PATH="$env:PATH;$env:JAVA_HOME\bin;$env:ANDROID_HOME\platform-tools;$env:ANDROID_HOME\cmdline-tools\latest\bin"

# 永久设置（需要管理员权限）
setx JAVA_HOME "C:\Program Files\Java\jdk-17" /M
setx ANDROID_HOME "C:\Users\$env:USERNAME\AppData\Local\Android\Sdk" /M
setx PATH "%PATH%;C:\Program Files\Java\jdk-17\bin;%ANDROID_HOME%\platform-tools;%ANDROID_HOME%\cmdline-tools\latest\bin" /M
```

### 4. 验证安装
在 PowerShell 中运行：
```powershell
java -version      # 应显示 Java 17
node --version     # 应显示 Node.js 版本
npm --version      # 应显示 npm 版本
adb --version      # 应显示 Android Debug Bridge 版本
```

## 项目构建步骤

### 1. 进入项目目录
```powershell
cd d:/ceshi/android/muyu
```

### 2. 安装依赖（如果需要）
```powershell
npm install
```

### 3. 构建 Release APK

**方法一：使用 Gradlew（推荐）**
```powershell
cd android
.\gradlew.bat clean
.\gradlew.bat assembleRelease
```

**方法二：使用 React Native CLI**
```powershell
npx react-native build-android --mode=release
```

### 4. APK 文件位置
- Debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`
- Release APK: `android/app/build/outputs/apk/release/app-release.apk`

### 5. 安装到设备
```powershell
# 连接设备并开启 USB 调试
adb devices

# 安装 APK
adb install android/app/build/outputs/apk/release/app-release.apk
```

## 快速配置脚本

运行以下批处理脚本自动配置环境：

```batch
@echo off
REM 设置环境变量
set JAVA_HOME=C:\Program Files\Java\jdk-17
set ANDROID_HOME=C:\Users\%USERNAME%\AppData\Local\Android\Sdk
set PATH=%PATH%;%JAVA_HOME%\bin;%ANDROID_HOME%\platform-tools;%ANDROID_HOME%\cmdline-tools\latest\bin

echo 环境变量已设置
echo.
echo 验证安装...
java -version
echo.
node --version
echo.
npm --version
echo.
adb --version
echo.
echo 按任意键继续构建项目...
pause
```

## 常见问题

### 1. Gradle 构建失败
- 检查 JDK 版本是否为 17
- 确保 Android SDK Build-Tools 34.0.0 已安装

### 2. 找不到设备
```powershell
adb devices
# 如果没有设备，确保已开启 USB 调试
```

### 3. npm install 失败
```powershell
# 清除缓存
npm cache clean --force
# 重新安装
npm install
```

### 4. Android SDK 版本不匹配
需要在 Android Studio 的 SDK Manager 中安装：
- Android 14.0 (API 34)
- Android SDK Build-Tools 34.0.0
- Android SDK Platform-Tools
