## 用户需求

用户需要为"敲木鱼"(WoodenFish)移动应用项目生成完整的产品文档，包含所有功能的详细说明。

## 产品概述

"敲木鱼"是一款基于 React Native 开发的 Android 移动应用，提供虚拟木鱼敲击和电子念珠功能。应用支持敲击计数、念珠拨动、自定义设置等核心功能，用户可以自定义木鱼图片、音效、漂浮文案等内容。

## 核心功能

- 木鱼敲击：点击木鱼增加功德计数，支持震动和音效反馈
- 念珠拨动：108颗念珠循环拨动，手势滑动增加功德
- 自定义设置：支持自定义木鱼图片、音效、漂浮文案、文字颜色等
- 数据持久化：自动保存计数和设置，应用重启后恢复

## 技术栈

- **框架**: React Native 0.73.6
- **语言**: TypeScript 4.8.4
- **平台**: Android (API 23-35, Android 6.0 - Android 15)
- **包名**: com.woodenfish
- **版本**: 1.0.0

## 核心依赖

- `@react-native-async-storage/async-storage`: 本地数据存储
- `react-native-document-picker`: 文档选择器（音效上传）
- `react-native-fs`: 文件系统操作
- `react-native-image-picker`: 图片选择器
- `react-native-safe-area-context`: 安全区域适配
